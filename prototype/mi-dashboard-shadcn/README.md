# MI dashboard shadcn prototype

This is an isolated Vite + React + shadcn/ui proof of concept. It is separate from the existing `site/` application and does not share its build or deployment path.

## Run

```powershell
npm install
npm run dev
npm run build
npm run lint
```

The prototype includes a desktop-first research portal shell, an executive summary, and a filterable cumulative production chart using mock data only.
